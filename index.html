OPPSETT

Home Assistant er ikke koblet til ennå

Appen trenger tre Vercel-miljøvariabler: HA_URL, HA_TOKEN og APP_PIN. Tokenet blir kun brukt på serveren og sendes aldri til iPhone.

Vis oppsett
  1. Lag et Long-Lived Access Token i Home Assistant-profilen din.
  2. Åpne Vercel → prosjektet → Settings → Environment Variables.
  3. Legg inn HA_URL, HA_TOKEN og APP_PIN.
  4. Redeploy prosjektet.
